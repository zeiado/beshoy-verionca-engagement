# Felopater & Ledia — Engagement Invitation

A bilingual engagement invitation with an animated envelope, butterflies, botanical decorations, and a responsive RSVP form.

- `index.html`: Arabic by default.
- `en.html`: English by default.
- Both pages include a language switch and embedded artwork.

Open either HTML file in a browser, or serve the repository as a static website.

## RSVP and music

The RSVP form needs a compatible `window.storage.set` integration to save responses. Until connected, it explains that online RSVP is unavailable; no response is recorded.

Music is disabled until an audio source is provided.
